## 本次行为变化

- bash 真实启动 PowerShell/Bash，固定 pwd/ls，精确字面值授权；无模型参数拼接。继承环境清空，stdin 启动门在 Windows Job Object / Linux 进程组建立后才释放。两个流共享 16 KiB 上限，执行最多 5 秒；超时、取消、超限、正常父进程退出和应用退出回收进程树。日志显示真实 PID、退出码和耗时，工作区路径脱敏。
- 页面打开时独立每 30 秒检查当前模式收件箱，新简报提示并更新列表；活动任务的 2 秒轮询停止后，收件箱检查仍保留。页面关闭不影响后台服务的扫描器。
- 模型请求记录关联 ID、配置版本、消息/schema 哈希及输入估计；响应记录相同 ID、供应商响应 ID、finish_reason 和有界工具请求摘要。工具调用 ID 可与执行记录核对，演示脚本结束字段明确标识。请求保存有界元数据而非完整敏感提示或模型内部思考。
- live 邮件配置未就绪时，页面明确提示，服务端拒绝保存 EMAIL 偏好；INBOX 无需 SMTP。
- 架构、工程方案、设计图与 README 已同步修订；历史设计中的“待实施”文本为设计时状态，当前交付状态以本文为准。
