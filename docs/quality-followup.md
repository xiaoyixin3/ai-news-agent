# v1.1 补齐记录：中断审计与内容质量

日期：2026-10-11。以用户提供的 architecture-v1.1.md 为基线，不改写架构原稿或既有真实简报。

## 本次已完成

- 工具批次中途取消或超时：已完成调用保留；当前工具记录 interrupted 与原 step_id，提示结果未确认；后续调用逐条记 not_executed，停止模型循环。先前文件/网络副作用不会回滚。整批超预算、重复调用 ID 和模型回复后取消也记录整批未执行。
- 以数据库已裁决的终态为准，watchdog 超时保留 DEADLINE_EXCEEDED，用户取消保留 USER_CANCELLED，不把中断统一误记为 CANCELLED。取消排队任务立即生成终态审计。
- 页面区分执行中止和未执行；终态任务中缺少结束事件的工具显示“结果未确认”，避免重启后仍显示执行中。工具成功率分母只含完成的 ok/failed，中止、未执行单列并在统计页面展示。
- 默认摘要目标 100–200 字；正文摘要硬上限 360、RSS 摘录 160、意义说明 160、导语 300。超长候选明确拒绝，保留前一个已接受版本，不静默截断。schema 错误给出字段路径、实际字数和允许范围，统一以 Unicode 码点统计。
- 提示词要求每条只使用当前来源证据；程序拦截明显混入其他已注册来源标题或链接且当前证据没有该内容的摘要。该规则不等于通用事实核验或语义去重。
- Java 离线质量评估工具可创建模板、校验引文/证据哈希、区分人工与辅助标注，按事实数量统计。源文件、输入和标签哈希留在结果中；不自动填充站内人审分数。
- 本地 HTTPS 服务使用域名匹配但不受信任的真实证书进行握手，生产默认 TLS 校验拒绝连接，HTTP 请求次数为 0。该测试补上证书故障验证，不代表所有网站的 TLS 状态。
