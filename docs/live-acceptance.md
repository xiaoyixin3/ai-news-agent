## 新闻网络与工程修复

- 使用实际 Java 传输验证：Hugging Face、Ars Technica 和 Google News RSS 均成功；前两个来源的正文也可读取。
- Google News 某些文章链接只返回 11 字符的跳转占位文本。生产工具拒绝把少于 120 字的真实提取结果缓存为正文，未读正文继续标记 rss_excerpt。
- 本机代理已配置，但最初 Java 新闻传输走直连，导致 DNS/请求失败与首轮总超时。现支持显式本机 SOCKS 代理、固定公共 HTTPS DNS；新闻地址仍经公网检查，代理使用数字 IP，保留原域名 TLS 校验。SOCKS 协议级测试验证了实际传输的数字地址和 Host。
- 搜索预览缩为最多 5 条，省略长跳转链接，完整来源保留在只读索引。此前联调还触发过上下文/累计预算上限，失败记录保留；没有将失败算成成功。
- 模型每轮收到可信的剩余时间、轮次、工具次数、预算与发布余量反馈。硬上限继续由服务端执行。本机 CONTEXT_TOKEN_LIMIT=64000，累计 RUN_TOKEN_LIMIT=100000，16 轮、40 工具、300 秒；发行默认上下文估计仍为 24000，可按模型能力配置。
