## 复现

```powershell
git clone https://github.com/xiaoyixin3/ai-news-agent.git
cd ai-news-agent
$env:PORT = '8096' # 仅在默认 8080 已占用时设置
.\start.cmd
```

打开 `http://127.0.0.1:8096/`，填写昵称和身份、保存偏好、点击生成；刷新并重新启动后确认历史保留。首次下载依赖需要可访问 Maven Central 的网络。本轮空缓存源码构建耗时已如实记录，预编译交付包包含 JAR，可跳过下载构建步骤。

浏览器验证使用 Playwright Chromium，Browser plugin not available；桌面 1440×1000、手机 390×844。交互路径为打开页面 → 新建订阅 → 生成 → 展开协议记录 → 查看统计 → 刷新 → 停服务 → 重新启动 → 同浏览器身份继续读取历史。截图位于仓库外的 outputs 目录，已逐张查看；QA 使用的 Node/Playwright 是验收工具，不是项目运行依赖。Linux、其他浏览器和真实服务不在本轮覆盖范围。
