# 页面实现约定

参考：ui-concept.png，1505 × 1045。纯白背景、蓝色按钮、浅灰边框，左侧订阅表单，右侧收件箱与运行记录。全站使用系统中文字体；无图片资产依赖。字号：品牌 29px，主标题 40px，区域标题 24px，表单与操作 15px，辅助文字 12–14px。边框 #dce2eb、正文 #111827、辅助文字 #6b7280、主色 #1269f8，圆角 6–7px。

必要的功能扩展：依据架构增加条数、回看时间、条件显示邮箱、历史分页与选择、简报来源、投递重试和可展开运行轨迹。默认时间 09:00，默认站内渠道，覆盖概念图的 08:00 和邮件样例值。动态内容由真实接口渲染，演示内容明确标注。

760px 以下单列，表单先于收件箱和运行记录。组件按请求封装 api.js、纯文本渲染 render.js、交互 app.js 分离。用户输入和新闻不作为 HTML 执行。
