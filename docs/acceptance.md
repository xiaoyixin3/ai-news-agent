## 自动化测试

`mvnw.cmd package`：19 个测试，0 失败、0 错误、0 跳过。

- FoundationTest：2 个，订阅、哈希令牌、持久化、迁移与时区参数。
- AgentTest：6 个，顺序变化、错误恢复、文件/Shell 边界、多工具依赖、轮次/次数限制、严格 JSON 与发布候选。
- DeepSeekProtocolTest：2 个，本地 HTTP 服务验证模型请求、工具 schema、tool_call_id、隐藏 reasoning_content 与截断响应拒绝。
- NewsQualityTest：3 个，来源约束、RSS 发布时间筛选、URL 规范化、私网和路径/junction 越界。
- TaskLifecycleTest：5 个，每日领取、并发/容量、事务/恢复、超时/缺少密钥、邮件失败与原子重试。
- ApiIntegrationTest：1 个，真实 Spring Boot HTTP 端口完整链路，包含多个状态和用户隔离断言。

测试使用临时数据库和模型/邮件模拟服务，不访问真实邮件收件箱，不消耗模型额度。
