# 累计模型预留不足与重复新闻反馈：修复记录

2026-10-11 的两次真实生成均触发 BUDGET_EXCEEDED。其中一次累计已知用量为 61807，但下一轮携带的历史交互已经超过 35 KB，保守输入预留加输出空间超过了剩余预算。该任务已取得有效候选，却未完成模型正常结束，因此没有正式保存简报。此错误是应用内的运行预算保护，不是模型账户余额不足。

## 修复行为

- 每轮按完整模型请求体估计上下文大小。较长上下文移除较早的完整交互，保留最新的 assistant/function-call 与 tool 结果配对，不留下悬空工具调用。
- 使用只读来源注册表生成有限工具数据快照，包括 RSS 摘录、已取得正文的短摘录与路径、正文不可用状态、近期重复来源标识，以及候选是否已接受。快照中的新闻文本仍是不可信数据，不是执行指令。
- 完整来源索引、正文、模型和工具审计仍保留在工作区及后台。上下文调整写入 context_compacted 事件，不清空累计模型用量或未知用量预留。
- 重复链接校验明确返回需要移除的 source_id；精简快照保留 duplicate_source_ids。全部来源重复时，模型可以提交说明原因的空简报。
- 工具顺序与自然终止仍由模型决定；候选 accepted 不等于正式发布，必须取得模型正常结束信号并再次校验后才保存。预算、轮次、网络和权限硬限制保持不变。

累计运行预算保持 100000，轮次保持 16，工具上限保持 40。提示版本为 news-1.1.4，工具 schema 版本仍为 1.1.3。首页继续只展示订阅偏好、简报历史和必要的生成状态。
